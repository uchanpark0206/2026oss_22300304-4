Key Learning: 이번 주 배운 핵심 내용 3가지

1)form은 기본방식인 get방식과 post방식으로 나뉘며 get방식은 url에 정보가 노출되어 비밀번호 같은것이 노출되면 사용자의 편의성 이 낮아지고 url공유 가능함.
post방식은 url에 정보가 표시되지 않아 비밀번호와 같은 사이트에 적합하고 url공유가 안됨

2)자바스크립트의 인라인 방식 익스터널 방식 인터널 방식 총 3가지 방식으로 사용 가능하며 인라인 방식은 원하는 테그에 직접적으로 사용하여 자바스크립트를 적용하는 방식이고,인터널 방식은 바디 안에 직접 넣어서 사용하는 방식이고 인라인 방식,마지막 익스터널 방식은 .js파일을 떠로 만들어 head안에 파일의 주소를 넣어서 적요하는 방식임 

3)자바스크립트는 객체지향언어이며 인처프리터 언어이며 객체지향적이라는 것은 프로그램을 단순히 순서대로 실행되는 명령어의 나열로 보지 않고, 여러 독립적인 '객체(Object)'들의 조립으로 파악하여 코드를 짜는 프로그래밍 언어를 의미하며,인터프리터 언어라는 것은 개발자가 작성한 코드를 미리 번역해 두지 않고, 실행할 때마다 한 줄씩 실시간으로 읽고 해석하여 컴퓨터를 작동시키는 프로그래밍 언어임
